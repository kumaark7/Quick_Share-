Quick Share VPS firewall baseline

Recommended public ports
- 22/tcp for SSH
- 80/tcp for HTTP
- 443/tcp for HTTPS

Recommended app exposure
- Do not expose 8788/tcp publicly if Nginx is proxying Quick Share.
- Bind Quick Share to localhost behind Nginx when possible.

Oracle Cloud ingress baseline
1. Keep SSH on 22/tcp.
2. Allow 80/tcp from 0.0.0.0/0.
3. Allow 443/tcp from 0.0.0.0/0.
4. Remove direct public access to 8788/tcp after Nginx proxy is confirmed.

If using UFW on Ubuntu
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw deny 8788/tcp
sudo ufw enable

If UFW is not installed
sudo apt update
sudo apt install ufw -y

Extra hardening
- Put rate limits in Nginx for /api/auth/ and /api/share.
- Add Fail2ban for repeated auth abuse.
- Restrict SSH to your IP if you have a stable address.
